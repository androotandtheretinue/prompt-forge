# Deferred work & Root’s decisions

The prototype is usable without settling these choices.

| Deferred feature | Decision for Root |
| --- | --- |
| Richer starter banks and user-defined axes | Which personality dimensions deserve a permanent place, and which should be optional packs? The ten initial axes are a provisional vocabulary. |
| AI Refine | Prefer local models, a user-supplied service, or a copy/paste workflow? All must produce reviewable proposals rather than silently changing canon. |
| Platform adapters | Which target comes first: plain system prompts, character-card formats, or a particular companion platform? Canonical JSON remains the source of truth. |
| More detailed Essence / Companion exports | How compact should deployment prompts be? Keep the current separate modules and explicit approval filtering. |
| Continuity records | Notes are implemented; source-linked events, corrections, retrieval, and memory consolidation need their own design. |
| Multiplex personas | Intentionally deferred; this document currently represents one character. |
| Forge Suite navigation | Keep independent instruments for now. Decide whether a shared suite index is useful after Music Forge’s shape is clearer. |

Current decisions: no compatibility constraints; unspecified relationship defaults; independent romance and erotic settings; manually chosen approval; complete JSON workspace exports; no character-license assumption; no paid API or account requirement; no telemetry; no automatic publishing of character data.
