# Prompt Forge 4.0.0 — DARPA

Prompt Forge has become a full-spectrum visual ideation instrument.

The original 1,343-option forge remains intact, but its possibility space now contains **2,000 unique signals across 16 axes**. Composition, Color Logic, and Story Signal let a prompt specify not merely how an image looks, but how attention moves, where color belongs, and what has just happened.

## Release highlights

- 20 total Forge Cards, including ASI Orchard, Tender Weapon, Haunted Interface, Sovereign Duet, Black-Site Angel, and Projection Cathedral.
- Three payload doctrines: RECON 6, STANDARD 10, and FULL 16.
- Controlled mutation and semantic cluster rerolls.
- Searchable Option Radar.
- Midjourney-aware flight controls with compatibility diagnostics.
- Persistent prompt history and a named Blueprint Vault.
- Strong locks that protect selections through every operation.
- A one-file app that remains easy to inspect, copy, remix, and redistribute.

## Why CC0

The forge is meant to propagate. CC0 lets artists, writers, teachers, developers, researchers, and delightful prompt goblins use the tool without waiting for permission or untangling attribution requirements.

Take it. Change it. Give the changed thing away again—or do not. The gift has no hook in it.

## Release verification

The release contains exactly 2,000 non-placeholder options with no duplicates. All 20 cards, category references, prompt ordering, randomization doctrines, locks, persistence paths, and model-parameter guards were tested before packaging.
